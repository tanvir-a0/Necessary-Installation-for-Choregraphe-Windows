# Necessary Installation for Choregraphe on Windows
<br>
This directory contains all the required files (or at least the ones I installed) during the setup of Choregraphe and while running the NAO robot on 19 January 2026.
<br>
The NAO robot runs correctly overall. However, there is a known issue: the “Run” button in Choregraphe works as expected, but the “Stop” button does not function properly.
<br>
Here, you can find the choregraphe-suite-2.5.10.7, which supports pepper robot with it's older firmware. Connecting for the first time always fails, but after that if you retry it connects successfully. 
<br>
<br>
Note: Install vcredist_x86.exe first then install vcredist_x64.exe second. Same for other files too (I did in this way).
